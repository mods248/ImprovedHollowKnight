# Improved Hollow Knight

Улучшает Hollow Knight: режимы боя, прокачка, новые механики и удобство.

> Требуется **Hollow Knight 1.5.x** и **Modding API** (ставится через Lumafly/Scarab автоматически).

## Возможности

### Бой
- **Два режима атаки** — режим «стрельба» (пули в стиле Cuphead, авто-прицел по врагам) и обычный гвоздь. Переключение по клавише (по умолчанию `C`, меняется в настройках мода).
- **Пули**: несколько навыков — двойная пуля, пробивные пули, чёрное пламя (поджигает врага), взрыв при добивании.
- **Гвоздь**: двойной удар, электро-клинок (цепная молния), смерч (AoE), критические удары.
- **Парирование** — короткое окно после удара поглощает урон врага (с синей вспышкой).
- **Пикировка** — в воздухе удар вниз резко прижимает героя к земле с усиленным ударом.
- **Скольжение** — на земле удар вниз проскальзывает в сторону движения.

### Прокачка (древо навыков, открывается клавишей `V`)
- Уровни здоровья, урона пуль, урона меча, скорости.
- Пассивные и активные навыки: восстановление души, регенерация, двойной прыжок, душа свыше, крик души, уровень персонажа.
- За убийство врагов капает опыт → очки прокачки.

### Мир и удобство
- Мини-карта с локатором босса.
- Аура сокровищ — подсветка разрушаемых стен.
- Локатор босса — стрелка по краю экрана в сторону активного босса.
- Дневник охотника — счётчик убийств за сессию.
- Шкала HP боссов, надписи за убийство боссов.
- Стартовое здоровье настраивается (по умолчанию 3 маски).
- Враги атакуют чаще, боссы — чуть быстрее (усложнение по умолчанию).

## Установка
1. Установи **Modding API** через Lumafly.
2. Поставь **Improved Hollow Knight** через Lumafly (или распакуй `ImprovedHollowKnight.dll` в `Mods/ImprovedHollowKnight/`).
3. Запусти игру.

## Настройки
В главном меню → Настройки → Настройки модов → **Improved Hollow Knight**: стартовое здоровье, кнопки режима/древа/карты.

## Сборка из исходников
Открой `ImprovedHollowKnight.csproj` в Visual Studio, собери в `Release` для `.NET Framework 4.7.2`. DLL кладётся в `Mods/ImprovedHollowKnight/`.

## Лицензия
Личный некоммерческий мод. Повторное использование кода — с указанием авторства.
